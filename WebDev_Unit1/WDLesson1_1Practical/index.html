Web Technologies

HTML

HTML (Hyper Text Mark Language)Pure Text data is "marked up".It is the structure of a web page and allows the browser to render what is inside of the web page. It is NOT a programming language its a markup language

CSS

CSS-(Casading Style Sheets)Is a style sheet language used for specifying the presentation and styling of a document written in a markup language such as HTML or XML.Elements include screen and paper. CSS is a cornerstone technology of the World Wide Web alongside HTML and JavaScript.

JavaScript

JavaScript is a high level programming language that serves one of the core technologies of the World Wide Web. JavaScript is a dynamic programming language used to make web pages interactive and alive. It works along side HTML and CSS to add features like animations pop up menus the real time content updates.

JQuery

JQuery is a JavaScript library designed to simplify HTML DOM tree traversal and manipulation. It is also a event handling CSS animations and Ajax. Its a free open source software using the permissive MIT license.
